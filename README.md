# Atlas Turbo

Aplicativo de desempenho e diagnóstico para Windows.

## Instalar

1. Abra a [versão mais recente](https://github.com/daltonrpj/atlas-turbo-releases/releases/latest).
2. Baixe `AtlasTurbo-Setup.msi` e execute o instalador.
3. Abra **Atlas Turbo** pelo atalho na Área de Trabalho ou no Menu Iniciar.

## Requisitos

- Windows 10 ou 11, x64.
- .NET Framework 4.8.
- [Microsoft Edge WebView2 Runtime Evergreen](https://developer.microsoft.com/microsoft-edge/webview2/).

O instalador inclui o runtime do aplicativo. Não é necessário instalar Node.js separadamente. As operações específicas que exigem administrador continuam sujeitas às permissões do Windows.

## Atualizar e remover

Feche o Atlas Turbo pelo menu da bandeja antes de instalar uma atualização. Para remover, use **Configurações → Aplicativos → Atlas Turbo**.

## Conferir o download

Cada versão inclui `SHA256SUMS.txt`. Compare o SHA256 do instalador com o valor desse arquivo.

Este repositório distribui os instaladores do aplicativo e instruções de uso.
